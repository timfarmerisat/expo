# Violet Forge

Somethingdifferent LLC's authenticated application engineering, sourced market research, AI asset generation, deployment readiness, project/task history, file vault, resource inventory, quote and profitability planning command center.

## Truth boundaries

- External provider connections are never shown as connected without verification.
- Market claims require a dated source URL.
- Quote revenue, cost, profit and margin are planning estimates until reconciled against actual transactions.
- Apple, Google Play, Microsoft Store, payments, DNS and arcade hardware remain setup-gated.

## Deployment

The production application is deployed through AppDeploy. AppDeploy injects `@appdeploy/client` and `@appdeploy/sdk`; do not add those packages manually.
